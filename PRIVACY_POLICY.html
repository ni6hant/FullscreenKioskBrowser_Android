Privacy Policy — Simple Android Kiosk Browser

Last updated: 2026-11-25

This app is open source. The complete source code is available on GitHub: FullscreenKioskBrowser_Android. You are free to audit, fork, and modify it.

1. Summary

Simple Android Kiosk Browser is a single-site fullscreen browser for Android. It displays one user-configured website in a WebView and keeps the screen awake while the app is in the foreground. We do not collect, store, transmit, or share any personal data.

2. Data we do NOT collect

  • No analytics, telemetry, or usage tracking of any kind.
  • No advertising SDKs or advertising identifiers.
  • No accounts, sign-in, or cloud services.
  • No crash reporting that transmits data off-device.
  • No third-party SDKs that phone home.

3. Data stored locally on your device

The app stores only the following, locally on your device (Android SharedPreferences, app-private, mode MODE_PRIVATE):

  • The website URL you configure.
  • Recovery toggles (reload on connectivity / on page failure).
  • Periodic refresh interval and unit.
  • Low-battery threshold and action.
  • Forced-orientation, pinch-to-zoom, and clear-cache toggles.

This data never leaves your device except as normal web navigation to the URL you configure.

4. Permissions

The app requests only:

  • INTERNET — to load the configured website.
  • ACCESS_NETWORK_STATE — to detect connectivity loss/restoration for recovery.

No camera, microphone, location, contacts, storage, or other permissions are requested.

5. WebView & security

  • JavaScript is enabled for site compatibility; no JavaScript bridges are exposed.
  • File access, universal access, and file-URL access are disabled.
  • TLS/SSL certificate errors are never bypassed.
  • Non-HTTP(S) URI schemes are blocked.

6. Children's privacy

The app does not knowingly collect any information from anyone, including children under 13. It contains no ads and no in-app purchases.

7. Open source

This app is open source under the repository FullscreenKioskBrowser_Android. You can inspect the source code to verify every claim in this policy.

8. Contact

For questions about this privacy policy, contact the developer via the GitHub repository's issue tracker.

This privacy policy applies to the Simple Android Kiosk Browser mobile application.
